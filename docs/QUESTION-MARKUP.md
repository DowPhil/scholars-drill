# Maths and chemistry in questions

How to type formulas in a question, its options, its explanation or a passage, so students see proper notation. Anything outside `$...$` shows exactly as typed.

Put the maths between dollar signs: `$x^2$`. For a real dollar sign, type `\$`.

## Maths

| You type | Students see |
|---|---|
| `$x^2$`, `$x^{2n}$`, `$x^{-1}$` | x², x²ⁿ, x⁻¹ (powers) |
| `$a_1$`, `$a_{n+1}$` | a₁, aₙ₊₁ (subscripts) |
| `$\frac{2}{3}$` | a stacked fraction, 2 over 3 |
| `$8^{\frac{2}{3}}$` | 8 to the power two-thirds |
| `$\sqrt{16}$`, `$\sqrt[3]{8}$` | square root, cube root |
| `$\log_{10} 2$`, `$\ln x$`, `$\sin 30\degree$` | log₁₀ 2, ln x, sin 30° |
| `$\times$ $\div$ $\pm$ $\le$ $\ge$ $\ne$ $\approx$` | × ÷ ± ≤ ≥ ≠ ≈ |
| `$\pi$ $\theta$ $\alpha$ $\beta$ $\lambda$ $\mu$ $\omega$ $\Omega$ $\Delta$ $\infty$` | π θ α β λ μ ω Ω Δ ∞ |
| `$2 \text{ m/s}^2$` | words or units inside maths, upright |

Use `{ }` to group: `$x^{10}$`, not `$x^10$` (that is x¹ followed by 0).

## Chemistry

Wrap formulas in `\ce{...}`. Element symbols stay upright and numbers after an element or bracket become subscripts on their own.

| You type | Students see |
|---|---|
| `$\ce{H2SO4}$` | H₂SO₄ |
| `$\ce{Ca(OH)2}$` | Ca(OH)₂ |
| `$\ce{SO4^{2-}}$`, `$\ce{Na^+}$` | sulfate ion with charge 2−, Na⁺ |
| `$\ce{C_nH_{2n+2}}$` | the alkane general formula |
| `$\ce{2H2 + O2 -> 2H2O}$` | an equation with →; a number after a space stays full size |
| `$\ce{N2 + 3H2 <=> 2NH3}$` | an equilibrium with ⇌ |

## If something is mistyped

A formula that cannot be read, such as a missing `}`, shows exactly as typed rather than breaking the question. Preview a question before publishing it.
